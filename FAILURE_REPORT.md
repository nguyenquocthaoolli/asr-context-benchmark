# Behavior report: conflicting initial prompt substitutes a name in Whisper tiny.en

Status: reproducible behavior report, not an assertion of a new implementation bug.

## Observation

For one fixed synthetic clip whose TTS input is “My name is Mira Patel.”, no prompt gives “My name is Mira Patel.” A conflicting directory prompt gives “My name is Nina Patel.” The same outputs occurred in the pilot and all three additional transcription calls per condition.

## Minimal reproduction

From the package root, after the setup in README.md:

```bash
.venv/bin/python run_benchmark.py --model-dir models/tiny.en \
  --sample name_en-gb_clean --repetitions 3 --output results/new-name-repro
```

The script compares these prompts, with independent transcription calls:

- None: `initial_prompt=None`
- Relevant: `The customer directory includes Mira Patel and Nora Chen.`
- Conflicting: `The customer directory includes Nina Patel and Laura Chen.`

Equivalent transcription settings are `language="en", beam_size=5, temperature=0.0, condition_on_previous_text=False, vad_filter=False, word_timestamps=False`, with CPU int8 and four threads. The reference text is not supplied to the ASR call. The relevant prompt intentionally contains candidate target vocabulary.

- TTS input: `My name is Mira Patel.`
- Synthetic fixture. On 2026-11-02 the project owner listened to this clip and confirmed hearing “Mira Patel.” This confirms the highlighted name with one listener, not the entire dataset.

## Expected and observed behavior

For this experiment, success means preserving the spoken name even when the provided context contains a different candidate. This is an evaluation objective, not a claim that the model promises to ignore conflicting prompts.

| Condition | Pilot | Repeat 1 | Repeat 2 | Repeat 3 |
|---|---|---|---|---|
| No prompt | Mira Patel | Mira Patel | Mira Patel | Mira Patel |
| Relevant prompt | Mira Patel | Mira Patel | Mira Patel | Mira Patel |
| Conflicting prompt | Nina Patel | Nina Patel | Nina Patel | Nina Patel |

All full transcripts begin “My name is” and end with the names above. Raw evidence is in `results/pilot/raw.jsonl` and `results/reproduction/raw.jsonl`.

## Scope and caveats

The example was selected after the full 144-transcription pilot; all pilot outputs are included. Misleading context actually has lower aggregate lexical WER than no context in the full pilot (27.73% vs 40.91%), so this example must not be used to claim that context generally harms recognition. This is a small offline model with synthetic speech, not a production streaming model. Deterministic repetition is not independent statistical evidence. Additional listeners and replication on other models/hardware remain useful next steps.
